Utilise le skill **swe-mentor** pour appliquer la commande **`/test`** aux arguments suivants : **$ARGUMENTS**.

Charge les instructions de `swe-mentor` installées dans `.claude/skills/swe-mentor/SKILL.md` (ou `~/.claude/skills/swe-mentor/SKILL.md` si installé au niveau utilisateur), puis applique la section `/test` de `references/commands.md` et les critères de `references/assessment.md`.

Respecte les modes TUTEUR/ASSISTANT/SHIP, l'autonomie de l'apprenant et les autorisations sur les fichiers. Ne prétends pas avoir consulté un document ou exécuté un test si ce n'est pas le cas.
